# Changelog

All notable changes to the **ETIS Engineering Platform Starter Kit** are documented in this file.

This repository is the source for the ETIS Engineering Platform, the professional reference and implementation environment for applying the Engineering Trustworthy Intelligent Systems (ETIS) framework.

## [Unreleased]

### Changed

- Aligned the repository README with the current ETIS Framework and Engineering Platform architecture.
- Clarified the Engineering Platform as a professional reference and implementation environment.
- Clarified the distinction among reusable templates, completed reference examples, Project Workspace patterns, and project-specific engineering evidence.
- Standardized Engineering Platform Starter Kit terminology to distinguish this repository from course-specific starter kits.
- Strengthened contribution guidance, engineering boundaries, review expectations, and licensing guidance.
- Expanded the security policy to cover private vulnerability reporting, dependency and supply-chain security, GitHub Actions security, sensitive information, and downstream engineering risk.
- Strengthened the Code of Conduct around professional engineering disagreement, evidence-centered review, reporting, and enforcement.
- Restored the canonical MIT License text.
- Expanded repository notices, attribution guidance, reference-example boundaries, and engineering responsibility language.
- Updated citation metadata and corrected the `CITATION.cff` structure.

### Security

- Established GitHub Private Vulnerability Reporting as the preferred vulnerability-disclosure mechanism.
- Added explicit security review expectations for reusable guidance, templates, workflows, dependencies, reference examples, and publication infrastructure.

## [1.0.0] - 2026-07-09

### Added

- Initial public release of the ETIS Engineering Platform.
- Engineering Stages ES-100 through ES-114.
- Guided engineering lifecycle with readiness gates.
- Repository-centered engineering workflow.
- Evidence-centered engineering practices.
- Cross-cutting governance integration.
- Reusable engineering templates spanning the lifecycle.
- Architecture, requirements, planning, implementation, testing, release, operations, governance, and stewardship artifacts.
- Shared repository assets and engineering workspace templates.
- Completed LMU/COICP reference implementation and lifecycle evidence.
- Project Workspace structure for organizing project-specific engineering artifacts.
- Platform Overview and onboarding guidance.
- MkDocs Material documentation site.
- GitHub Actions continuous integration.
- GitHub Pages automated deployment.
- Strict MkDocs validation.
- Link verification.
- SEO metadata.
- Sitemap generation.
- `robots.txt` support.
- GitHub Issue and pull request templates.

### Established

- Baseline public Engineering Platform implementation.
- Template Library.
- LMU/COICP reference examples.
